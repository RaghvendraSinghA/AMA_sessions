# Questions and Answers

### Q: Why is the `:hover` pseudo-class used in CSS?
      Ans: To apply styles when the mouse hovers over an element.

### Q: If CSS contains one ID selector and five class selectors, which has the highest priority?
      Ans: The ID selector, ID selector css will be applied to element.

### Q: What is normalization in databases?
      Ans: Organizing data to reduce redundancy and inconsistency. 
           Examples: First Normal Form, Second Normal From, Third Normal Form etc.

### Q: What is the LIKE clause used for in SQL?
      Ans: To search for a pattern in value of column.

### Q: What is the purpose of the placeholder attribute?
      Ans: To show a hint inside a form input button, like example of what you     
            should write inside input button.

### Q: Which SQL command deletes a database?
      Ans: DROP DATABASE database_name;`

### Q: What is inheritance in OOP?
      Ans: It allows a class to inherit properties and methods from another class.   

### Q: What does background-size: cover do?
      Ans: It covers the entire element, it fills entire image inside container     
            element if image is used as background, crops the image if necessary.   

### Q: What is the difference between 'link' and 'a' tag?
      Ans: <link> : connects external resources to current page,    
           <a> : creates clickable links through which we can navigate to different    
                 webpages, sections of current website and we can also visit to    
                  other websites.

### Q: What is z-index in CSS?
      Ans: It controls the stacking order of elements.

### Q: What is the difference between font-weight and font-size?
      Ans: font-weight controls thickness of text while font-size controls size    
      of text.

### Q: What are the types of inheritance in OOP?
      Ans: Single, multiple, multilevel, hierarchical, and hybrid.

### Q: What is the difference between sticky and fixed positioning?
      Ans: fixed stays relative to the viewport, sticky sticks to top or bottom    
            of its container while scrolling.
